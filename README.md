# XinStudyFile

> 个人学习笔记整理仓库 · 数学知识体系

本仓库系统整理了 **高等数学** 与 **高中数学** 的核心知识，按章节分文件组织，便于复习与查阅。

## 仓库结构

```
XinStudyFile/
├── 高等数学/        # 大学高数（上下册）知识整理
│   ├── README.md
│   └── 01 ~ 08 章
└── 高中数学/        # 高中数学全模块知识整理
    ├── README.md
    └── 01 ~ 10 章
```

## 文档规范

- **格式**：Markdown，公式使用 LaTeX（行内 `$...$`，行间 `$$...$$`）
- **结构**：每章按「概念定义 → 公式/定理 → 典型题型 → 易错点与拓展」组织
- **结尾**：附"本章小结"与"常见题型速查表"
- **高中数学**章节另附高考真题举例（标注年份与卷别）
- **风格**：简约、无 emoji，适合在 VSCode / Typora / Obsidian 等编辑器中阅读

## 使用建议

1. 从对应目录下的 `README.md` 入口开始浏览，含可点击的章节链接与学习路线图。
2. 数学公式需在支持 LaTeX 渲染的 Markdown 编辑器中查看。
3. 建议按目录学习路线顺序复习，前后章节存在依赖关系。
