## 学习与复习路线建议

```
集合与逻辑（工具）─▶ 函数（核心）─▶ 基本初等函数
       │                │
       ▼                ▼
   不等式           三角函数 ──▶ 解三角形
                         │
                         ▼
   向量复数 ◀──── 数列 ◀─── 计数原理
       │                       │
       ▼                       ▼
   立体几何 ──▶ 解析几何 ──▶ 概率统计
                    │
                    ▼
              导数应用（函数压轴）
```

- **主干一**：函数 → 导数 → 函数压轴。
- **主干二**：解析几何（直线圆 → 圆锥曲线 → 轨迹与最值）。
- **主干三**：立体几何（几何体 → 位置关系 → 空间向量）。
- **数据线**：计数原理 → 概率 → 统计。
