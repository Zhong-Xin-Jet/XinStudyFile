## 从入门到精通（摘要）

> 以下为学习路线概览，详细内容见 [从入门到精通.md](./从入门到精通.md)。

### 学习路线图

```
预备知识(高中函数/三角/解析几何/不等式)
      │
      ▼
第1章 极限与连续 ──▶ 第2章 一元微分 ──▶ 第3章 一元积分
(极限思想)            (导数/中值/泰勒)     (积分法/反常积分)
                                              │
                                              ▼
第8章 常微分方程 ◀── 第7章 无穷级数 ◀── 第6章 曲线曲面积分
(一阶/二阶/欧拉)     (幂级数/傅里叶)       (格林/高斯/斯托克斯)
                                              │
                                              ▲
                                        第5章 重积分 ◀── 第4章 多元微分
                                        (二/三重积分)       (偏导/全微分/梯度)
```

### 三阶段分级概览

| 章节 | 入门（基础） | 进阶（巩固） | 精通（拓展） |
| --- | --- | --- | --- |
| 1 极限与连续 | 极限计算、间断点分类 | 洛必达、反求参数、闭区间性质 | $\varepsilon-\delta$ 严格证明、实数连续性定理链 |
| 2 一元微分 | 导数计算、微分中值定理 | 泰勒展开、极值凹凸性、洛必达综合 | 中值定理逆向构造、极值点偏移 |
| 3 一元积分 | 换元法、分部积分、N-L 公式 | 反常积分审敛、定积分应用 | 含参积分、Gamma/Beta 函数深化 |
| 4 多元微分 | 偏导数、全微分、链式法则 | 隐函数、方向导数、拉格朗日乘数 | 多元泰勒、隐函数组定理 |
| 5 重积分 | 二/三重积分计算 | 极/柱/球坐标变换、对称性 | 变量替换定理、含参重积分 |
| 6 曲线曲面积分 | 两类积分计算 | Green/Gauss/Stokes 公式 | 外微分、统一 Stokes 公式 |
| 7 无穷级数 | 审敛法、收敛半径 | 幂级数求和、傅里叶级数 | 一致收敛、Abel/Dirichlet 判别 |
| 8 常微分方程 | 一阶方程类型识别 | 二阶常系数、欧拉方程 | Picard 存在唯一性、级数解法、Laplace 变换 |

### 时间规划

| 阶段 | 内容 | 时长 | 每周学时 |
| --- | --- | --- | --- |
| 上册 | 第 1-3 章 | 3-4 个月 | 8-10 小时 |
| 下册 | 第 4-8 章 | 4-5 个月 | 8-10 小时 |
| 综合复习 | 全册串讲 + 真题/考研题 | 2-3 个月 | 10+ 小时 |

### 里程碑检验

- **入门达标**：能独立完成各章基础计算与证明，课本习题正确率 80%+
- **进阶达标**：能处理考研常规题型，期中期末考试 75+（百分制）
- **精通达标**：能挑战考研压轴与竞赛题，理解定理证明与反例构造

> 详细自测题（每章 5 道，共 40 道）与进阶方向见 [从入门到精通.md](./从入门到精通.md)。

## 学习路线建议

```
极限与连续 ──▶ 一元微分 ──▶ 一元积分 ──┐
                                       │
                                       ▼
常微分方程 ◀── 无穷级数 ◀── 多元微分 ◀── 重积分
                  │
                  ▼
            曲线/曲面积分（多元积分学高峰）
```

- **主线一（上册）**：1 → 2 → 3，构成一元微积分核心。
- **主线二（下册）**：4 → 5 → 6，多元微积分。
- **横向工具**：7（级数）与 8（微分方程）依赖前 6 章基础。
