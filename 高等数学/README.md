## 学习路线建议

```
极限与连续 ──▶ 一元微分 ──▶ 一元积分 ──┐
                                       │
                                       ▼
常微分方程 ◀── 无穷级数 ◀── 多元微分 ◀── 重积分
                  │
                  ▼
            曲线/曲面积分（多元积分学高峰）
```

- **主线一（上册）**：1 → 2 → 3，构成一元微积分核心。
- **主线二（下册）**：4 → 5 → 6，多元微积分。
- **横向工具**：7（级数）与 8（微分方程）依赖前 6 章基础。

## 常用数学符号约定

| 符号 | 含义 |
| --- | --- |
| $\forall$ | 任意 |
| $\exists$ | 存在 |
| $\Rightarrow$ | 推出 |
| $\Leftrightarrow$ | 等价 |
| $\to$ | 趋于 |
| $\Delta$ | 增量 |
| $\text{d}$ | 微分算子 |
| $\partial$ | 偏导数 |
| $\sum$ | 求和 |
| $\int$ | 积分 |
| $\lim$ | 极限 |
| $f'(x), f''(x)$ | 一阶、二阶导数 |
